# Student Management System

A student management system implemented in C language.

## Introduction

This project is a student management system developed using C.
It uses linked lists and file operations to manage student and teacher information.

## Features

- Administrator login
- Student information management
- Teacher information management
- Add student/teacher information
- Delete student/teacher information
- Modify information
- Search information
- Display all information
- Save data to files
